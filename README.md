# Chrome_DownloadAsMD

Chrome extension to download a single page as Markdown or download a site (same-origin links from the current page) as a folder of Markdown files.

## Install

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select your local clone of this repository folder.

## Use

1. Open a page you want to export.
2. Click the extension icon.
3. Choose:
   - **Download This Page** to save one `.md` file.
   - **Download This Site** to save multiple `.md` files in a host folder (one file per discovered same-origin page).
